# Cedarbridge-Ticketing
Project Overview

A cloud engineering project focused on designing, deploying, securing, and operating an internal IT ticket management system using Microsoft Azure.

The solution aims to centralize IT requests, improve ticket ownership and status tracking, provide operational visibility, and support a consistent ticket lifecycle.

Project Objectives

Deliver a functioning IT ticketing application.

Design and deploy supporting Azure infrastructure.

Implement secure authentication and authorization.

Use Terraform for Infrastructure as Code.

Implement automated testing and CI/CD.

Establish monitoring, logging, and recovery capabilities.
